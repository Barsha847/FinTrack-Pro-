FAQ

Frequently Asked Questions

Find answers to common questions about the platform, security, and future integrations.

Is my data secure on FinTrack Pro?

Yes, absolutely. For Phase 1 we have implemented rigid client validations. For Phase 2, a secure PostgreSQL database layout with hashed passwords, parameterized PDO prepared SQL statements, and strict user ownership filtering rules will safeguard your assets from any malicious extraction.

Can I export reports in Excel or CSV format?

Yes. Under the Reports tab, users will be able to export custom range transactions. Our Phase 2 system supports exports to clean PDF documents, Excel spreadsheets, and raw CSV files, making third-party tax filings completely seamless.

Does this require any paid membership subscription?

No, this is built as a self-hosted open-source personal application suitable for local deployment. You can host it yourself using XAMPP or Docker with zero ongoing operational costs.
